# 进入编辑器

编辑器随《星际争霸 II》的所有版本一同提供，包括 自由之翼、虫群之心 和 虚空之遗。它也包含在免费的《星际争霸 II》Starter Edition 中。你可以前往下图所示的 us.battle.net/arcade/en/download 下载 Starter Edition。

![Client Download Page](./resources/002_Getting_to_the_Editor01.png)



下载客户端后，你就可以通过 Battle.net 启动器进入编辑器。

![Battle.net Launcher](./resources/002_Getting_to_the_Editor02.png)

你会在启动器中标题链接的下方找到“启动编辑器”按钮。下图展示了它在两个版本启动器中的位置。

![Client Header Links](./resources/002_Getting_to_the_Editor03.png)

你也可以在本地找到编辑器入口，包括 StarCraft 安装目录和开始菜单中的快捷方式。它的图标如下图所示。

![Editor Icon](./resources/002_Getting_to_the_Editor04.png)

另外，直接打开任何原生 `.SC2Map` 文件也会启动编辑器。它们的图标如下图所示。

![Map Icon](./resources/002_Getting_to_the_Editor05.png)

在《星际争霸 II》登录界面的左侧，你还会看到一个带有 “Open Editor” 链接的标签页。该菜单如下图所示。

![Login Screen Editor Link](./resources/002_Getting_to_the_Editor06.png)

启动之后，编辑器会在加载时显示启动画面。根据你的游戏设置以及默认要加载的地图，这个过程可能需要一些时间。启动画面如下图所示。

![Editor Start-up Screen](./resources/002_Getting_to_the_Editor07.png)
