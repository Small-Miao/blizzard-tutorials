# 编辑器历史

暴雪曾随旗下 RTS 游戏发布过多套编辑工具。每一次新作推出，这些工具的能力都会进一步增强，为社区带来更广阔的创作空间。正是这样长期的发展与打磨过程，最终造就了今天的《星际争霸 II》编辑器。本文将简要回顾这些编辑器的历史，其中不少工具直到今天仍有人在积极使用，以便帮助你更好地理解《星际争霸 II》编辑器的来历。

![图像](./resources/017_Editor_History01.png)

WarCraft II 地图编辑器发布于 1995 年。玩家第一次有机会进入开发者工具，亲手制作自己的地图，无论是和朋友进行对战，还是制作自定义战役都成为可能。

[![Map Editor View](./resources/017_Editor_History02.png)](./resources/017_Editor_History02.png)
*地图编辑器视图*

显著新增功能

  - 用户第一次可以使用编辑器为暴雪 RTS 制作自定义任务。
  - 地形可由七种元素构成，并支持多种地图尺寸。
  - 可以在地图上放置游戏中的全部主要资源。
  - 可使用任意单位、建筑和战役英雄，并将其分配给最多八个玩家阵营。
  - 可以把地图设置为四种可用地块集之一。
  - 可以编辑升级花费、初始资源和单位属性。
  - 可以为八个玩家阵营分别指定不同 AI 控制器。

在 WarCraft II 地图编辑器中，地图的全部自定义设置都通过五个属性窗口完成配置，如下图所示。

[![Editor Properties Windows](./resources/017_Editor_History03.png)](./resources/017_Editor_History03.png)
*编辑器属性窗口*

当时并不支持任何可用于丰富项目的自定义逻辑、自定义对象或类似系统。不过，即便如此，仍然出现了许多利用创意地形和单位摆放来构建有趣体验的独特地图。

[![WarCraft II Map Creations](./resources/017_Editor_History04.png)](./resources/017_Editor_History04.png)
*WarCraft II 地图作品*

![图像](./resources/017_Editor_History05.png)

StarCraft Campaign Editor 发布于 1998 年。由于加入了触发器这一类脚本逻辑，地图作者可以使用的选项大幅扩展。新的 Battle.net 也使玩家之间分享地图与联机游玩变得容易得多，从而让自定义作品的受众数量迅速增长。

[![Campaign Editor View](./resources/017_Editor_History06.png)](./resources/017_Editor_History06.png)
*战役编辑器视图*

显著新增功能

  - 现在加入了通过触发编辑器实现的自定义逻辑系统。
  - 可以使用 Mission Briefings Editor 制作任务前的剧情说明片段。
  - 地块集可以再叠加一层多样化的环境装饰物。
  - 可以在地图中绘制战争迷雾数据。
  - 可以导入自定义音效，并用于叙事片段或其他效果。
  - 可以在地图上构建会响应玩家行为并驱动触发器的地点。
  - 单位和英雄可以重命名，使地图作者能够赋予地图新的想象主题。

新加入的任务序列编辑器和触发逻辑编辑器，大大拓宽了整体编辑体验。

![](./resources/017_Editor_History07.png)
*Mission Briefings Editor -- Trigger Editor*

借助活跃的线上社区和扩展后的工具，各式各样的新游戏类型与故事被创作并分享出来。许多通过这些工具产生的创新，也推动了更广泛游戏世界的发展。

[![StarCraft Map Creations](./resources/017_Editor_History08.png)](./resources/017_Editor_History08.png)
*StarCraft 地图作品*

![图像](./resources/017_Editor_History09.png)

WarCraft III World Editor 发布于 2002 年。为了适应 3D 化以及 WarCraft III 本身的需求，编辑器的灵活性和规模都成长到必须拆分为多个独立模块的程度。工具已经不再只是一个单独编辑器，而成为一整套编辑套件，为用户提供了覆盖游戏开发主要领域的控制能力。

[![World Editor View](./resources/017_Editor_History10.png)](./resources/017_Editor_History10.png)
*世界编辑器视图*

显著新增功能

  - 编辑器现在由八个模块组成：Terrain Editor、Trigger Editor、Sound Editor、Object Editor、Campaign Editor、AI Editor、Object Manager 和 Importer Manager。
  - 可以在地图项目数据中创建全新的单位、对象、升级、技能、物品和英雄。
  - 可以设置自定义镜头，并在游戏过程中动态调用。
  - 触发器系统得到扩展，可提供更强大的游戏时脚本能力。

几乎所有工具能力的扩展，最终让编辑器成长为一套模块化工具集。

![](./resources/017_Editor_History11.png)
*Object Editor Module -- Trigger Editor Module*

到这个阶段，RTS 编辑工具已经真正成长为一套强大的游戏开发套件。凭借至今仍然活跃的社区以及悠久的项目发布历史，WarCraft III World Editor 仍然是设计学习者、爱好者和玩家的心头好。
