# 标准依赖项

《星际争霸 II》三部曲中使用的每一种数据资源，都是通过某个依赖模组分发的。这些标准依赖项建立在游戏基础模组 Core.SC2Mod 之上，并提供与《星际争霸》特定版本相关的资源。本文会逐一拆解每个标准依赖项，说明其用途、内容，以及它所依赖的其他依赖项。
