# 《星际争霸 II》编辑器指南
欢迎来到《星际争霸 II》编辑器指南！在这里，你可以找到官方与社区作者贡献的各类指南。

## Blizzard 指南

这些指南由 Blizzard 官方编写或赞助。这里包含两套指南：

* [入门教程](./Classic_Tutorials/01_Terrain_Module/1/)：这些教程最初发布在《星际争霸 II》官方网站上。它们非常适合作为熟悉编辑器的起点，其中也包含几组对特定功能讲解得相当深入的指南。


* [完整编辑器指南](./New_Tutorials/01_Introduction/001_Editor_Introduction/)：这些教程由 Blizzard 赞助、由社区中的资深作者撰写。内容极其全面，跟着学习后你会对编辑器建立很扎实的理解。
