# 数据模块 - 第 2 部分

## II. 修改单位名称/生命值/护甲/能量

终于要开始改数据了！我们首先会修改一些简单的单值字段，先热热身。这里要改的是 Jim Raynor (Commando) 的名称、生命值、护甲和能量。

### A. 打开 单位 数据目录：

1. 默认情况下，单位 数据目录应该已经打开；如果没有，请点击工具栏下方的 “+” 标签页，打开可用目录的上下文窗口。
2. ![img](016-changingunitvalues-opencatalogcontextmenu.jpg)

3. 选择 “Edit Game Data”，然后选择 “单位”。
4. ![img](017-changingunitvalues-openunitscatalog.jpg)

5. 单位 标签页会出现在刚才用于打开目录的 “+” 标签页所在的那组标签中。之后你每打开一个目录，都会多出一个对应标签。

### B. 名称

1. 在列表中滚动查找，或使用 单位 对象列表上方的搜索栏，找到并选中 Jim Raynor (Commando)。
2. 右键该对象，选择 “Modify Unit...”，或者在选中状态下直接按 [Enter]。
3. 输入你希望这个单位显示的新名称。这里我们将其命名为 “人民英雄”。
4. ![img](018-changingunitvalues-unitpropertieswindow.jpg)

5. 你会注意到旧名称的一部分仍然保留着：“(Commando)”。这是因为它并不是单位名称本体，而是单位名称的后缀。每个对象都可以附带一个前缀和后缀，它们会显示在编辑器里，但不会出现在游戏中。这样做是为了方便区分多个同名对象。本例中，战役里会用到 3 个不同版本的 Jim Raynor 单位，所以我们通过不同后缀在编辑器中区分它们。
6. 要移除这个单位后缀，请确保该单位仍被选中，然后在字段列表中找到 “Editor Suffix” 字段。双击该字段的值，弹出一个用于修改后缀的窗口。
7. ![img](019-changingunitvalues-doubleclickfieldvalue.jpg)

8. 删除 “(Commando)” 文本，然后按 OK。
9. ![img](020-changingunitvalues-editorsuffixwindow.jpg)

你可能会注意到，编辑器中我们的单位对象颜色从蓝色变成了绿色。这是因为该单位现在包含了当前地图专属的数据。基础配色规则如下：

- 灰色：基础、默认、核心玩法数据
- 蓝色：来自 Blizzard 依赖项或 Mod 的数据，例如 liberty 或 campaign 数据
- 橙色：来自自定义依赖项或 Mod 的数据
- 绿色：来自你当前正在编辑的地图文件的数据



C. 生命值

接下来，我们要修改雷诺的生命值。这里需要改 2 个字段值：Life Maximum 和 Life Starting Amount。我们把这两个值都改成 650。

![img](021-changingunitvalues-changedhealthvalues.jpg)

### D. 护甲

护甲值位于 Life Armor 字段下。我们把雷诺的护甲改成 3，同时也把 Life Armor Name 改成了 “人民护甲”。

### E. 能量

最后，我们要修改雷诺的能量。和生命值一样，这里也要修改两个字段：“Energy Maximum” 和 “Energy Starting Amount”。由于稍后我们会把他的技能改成不消耗能量，所以这两个值都设为 0。

### F. 测试效果

既然已经修改了一些单位数据，现在保存工作并运行地图查看效果。开始游戏并选中我们修改后的单位后，应该可以看到他拥有了新的名称、生命值、护甲、护甲名称，并且不再有能量：

![img](022-changingunitvalues-changedvaluesingame.jpg)



## III. 修改武器攻击频率和伤害

我们假装雷诺手上的枪并不是比其他陆战队员更强，只是他会花更多时间瞄准，然后更精准地命中要害。为了营造这种感觉，我们会把雷诺武器的攻击周期调慢，同时提高这把武器造成的伤害。

### A. 武器周期

单位的攻击信息并不是直接存储在单位数据中的。有时我们希望一个单位拥有不止一种攻击方式，比如刺蛇和蟑螂，它们都同时拥有近战与远程攻击。

因此，要修改武器的攻击频率，我们需要到 武器 数据目录中选中雷诺的武器。你既可以像之前一样通过 “+” 标签页打开 武器 目录，再从列表中找到雷诺的武器（名称为 Raynor - Gauss Rifle (Horner05S)）；也可以直接通过 Explorer 区域快速定位：

![img](023-changingunitvalues-selectweapon.jpg)

选中武器后，找到 Period 字段，并将其值改为 1.92，大约是默认攻击速度的一半。我们还把这把武器的名称从 Gauss Rifle 改成了 “人民之枪”。

### B. 武器伤害效果

武器的数据分布在两个不同位置。关于武器“如何被使用”的信息，存放在武器数据本身中；而武器被单位发射/使用后“会造成什么结果”的信息，则存放在效果目录（效果 Catalog）中。

效果是数据系统里真正推动事情发生的核心。只要有某个东西对另一个东西产生作用，背后通常就是通过效果实现的。技能、行为和武器都可以触发效果。灵能风暴技能会触发一组灵能风暴效果；母舰的隐形行为会周期性触发一个效果，用来搜索周围需要隐形的单位；武器在开火时同样也会触发效果。

本教程不会过多展开效果系统的工作原理。它非常强大，但也正因为如此，有很多内容需要解释。

- 效果会以一种类似树状的事件链方式展开。
- 一个效果可以再触发一个或多个其他效果，而每个效果都有自己的职责。
  - 有些非常简单。雷诺的武器只会调用一个效果，对武器目标造成伤害。
  - ![img](024-changingeffectsvalues-raynorweaponeffectstree.jpg)

  - 有些则复杂得多，例如灵能风暴。灵能风暴会先调用一个持续数秒的效果，这个效果会周期性调用另一个搜索小范围内单位的效果。该搜索效果会再对找到的每个单位调用一个伤害效果。
  - ![img](025-changingeffectsvalues-psistormeffectstree.jpg)
- 效果也分为不同类型。
  - 有些效果存在的目的只是触发其他效果。
  - 有些效果用于造成伤害。
  - 有些效果用于在某个区域内搜索单位。
