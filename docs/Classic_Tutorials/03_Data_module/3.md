# 数据模块 - 第 3 部分

## IV. 修改单位的技能组合

接下来，我们要修改英雄可以施放的技能。为单位设置技能分为两个步骤：先把技能添加到单位上，再把与该技能关联的按钮放进命令卡。

### A. 技能数组

如果单位本身不具备对应技能，那么我们就无法在命令卡上添加相关技能命令。因此，在修改命令卡之前，我们要先看看他的技能列表。

1. 打开 单位 数据目录后，选中 The People's Hero。
2. 找到 “技能 +” 字段，并双击其值区域。在打开的窗口中，你会看到该单位拥有的技能列表。
3. ![img](027-changingabilitiesvalues-abilitieslist.jpg)





在给英雄添加我们真正想要的技能之前，应该先把不需要的技能移除掉。

1. 要移除某个技能，选中它，然后点击窗口右侧的红色 “x” 按钮。
2. 对列表中的所有技能重复步骤 1，只保留 Stop、Attack 和 Move。这三个基础技能对于单位执行移动、巡逻和攻击等常规功能非常重要。
3. ![img](028-changingabilitiesvalues-deleteability.jpg)





现在只剩下基础技能了，接下来我们要把希望英雄拥有的特殊技能加回来。

1. 保持 “技能 +” 窗口打开，点击刚才红色 “x” 上方的绿色 “x” 按钮。
2. ![img](029-changingabilitiesvalues-addingability.jpg)

3. 在弹出的窗口中，打开下拉菜单并选择 Raynor Commando - Railgun Snipe 技能。
4. 重复步骤 1 和 2，再添加 Tychus - Toss Grenade 和 Swann - Place Turret 技能。全部添加完成后，点击 “Ok” 按钮关闭窗口。
5. ![img](030-changingabilitiesvalues-newabilslist.jpg)





现在技能已经准备好了，就可以把它们放到单位的命令卡上。

![img](031-changingcommandcardvalues-cmdcardwindow.jpg)

### B. 删除命令卡按钮

和技能列表一样，在添加新按钮之前，先把不想要的命令卡按钮删除掉。

1. 选中命令卡按钮区域左下角的按钮。
2. ![img](032-changingcommandcardvalues-buttonselected.jpg)

3. 你会注意到，下方字段会切换为显示这个按钮对应的设置。我们可以看到它的按钮名是 “Plant Breaching Charge”，命令类型是 “Ability Command” 等等。Ability 和 Ability Command 区域现在是空白的，因为就在刚才，我们已经从单位身上删除了这个按钮所引用的技能。

4. 要删除这个按钮槽位及其对应技能信息，请点击命令卡区域下方 按钮 区域右侧的红色 “x” 按钮。
5. ![img](033-changingcommandcardvalues-deletebutton.jpg)

6. 对 Grenade、Chrono Rift Device 和 Experimental Plasma Gun 按钮重复步骤 1 和 2。





现在就可以添加我们希望英雄使用的新按钮和对应命令了。

1. 选中左下角的按钮位置。
2. 点击刚才用于删除按钮的红色 “x” 上方的绿色 “x” 按钮。
3. ![img](034-changingcommandcardvalues-addbutton.jpg)

4. 在弹出的窗口中，找到并选中 Penetrator Round (Raynor) 按钮，然后按 OK。
5. ![img](035-changingcommandcardvalues-addcommandbutton.jpg)

6. 在 Command Type 下拉菜单中，选择 Ability Command。Ability Command 允许我们把这个按钮与单位已经拥有的某个技能关联起来。
7. 保持 Requirements 为 (None)。Requirements 用于决定按钮何时显示或隐藏，以及何时可用或禁用并呈灰色。我们希望这个技能始终可用、始终显示。
8. 在 Ability 一栏中，从技能列表里选择 Raynor Commando - Railgun Snipe。
9. 在 Ability Command 一栏中，选择 Penetrator Round (Raynor)。





![img](036-changingcommandcardvalues-finishedbuttonoptions.jpg)

按照同样的步骤，再为 Tychus - Toss Grenade 和 Swann - Place Turret 技能添加命令按钮：

![img](037-changingcommandcardvalues-finishedbuttonoptions2.jpg)

![img](038-changingcommandcardvalues-finishedbuttonoptions3.jpg)
