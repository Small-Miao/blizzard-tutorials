# 数据模块 - 第 4 部分

## V. 为单位添加动画

在测试这些技能时，你可能已经注意到了：当你命令 The People's Hero 使用技能时，他会像个呆子一样站在原地不动。当然，技能还是能正常释放，但他完全没有任何动作。看起来就像他能用肚脐发射手雷，或者光靠意念就能放下炮塔、让异虫爆炸一样。要让 The People's Hero 在使用技能时正确播放动画，我们就必须深入研究 Actor 数据目录。和效果目录一样，Actor 是一个非常灵活但也相当复杂的系统。

- 虽然 单位、技能、效果 以及其他目录定义了《星际争霸 II》中“会发生什么”，但 Actor 数据目录定义的是“发生时看起来和听起来像什么”。你在游戏中看到的每一个单位、效果和技能，都与某个 Actor 绑定。
  - 关于单位“如何工作”的信息，都存储在 单位 数据目录中：
    - 生命值
    - 能量
    - 技能
    - 移动速度
  - 关于单位“长什么样”的信息，则存储在 Actor 中：
    - 模型
    - 动画
    - 单位图标
    - 声音
- 和效果一样，Actor 也分为不同类型。Actor 可以用来控制：
  - 单位
  - 导弹
  - 声音
  - 效果
  - 等等
- 我们通过 Actor Message 来告诉 Actor 在什么时机做什么事。每条 Actor Message 都由一个 Event、零个或多个 Term，以及一个 Message 组成。
  - Event - 我们等待游戏中某件事情发生，以此触发发送给 Actor 的消息。比如，我们等待一辆恶蝠攻击某个目标。
  - Terms - 它有点像触发器中的条件。当事件发生后，我们会再检查某些游戏条件是否成立。比如，当恶蝠攻击某物时，我们会判断它是否拥有升级后的攻击。
  - Message - 这部分就是我们真正希望在事件发生时执行的内容。比如，当恶蝠攻击时，我们会让它播放攻击动画。





- 打开 Actor 数据目录。

- 选中 Raynor - Raynor。

- 找到并双击 “Events +” 字段值，打开 Actor Messages 窗口。你会在这里看到前面介绍过的 Event、Term 和 Message 这些概念是如何实际运作的。

  ![img](040-changingunitactor-actorwindow.jpg)





对于这个技能，我们要让 Raynor 的 Actor 播放攻击动画，因为这样会让他把枪口指向技能方向，看起来像是在射出 Penetrator Round。

### 创建事件

1. 要创建一个新事件，在 Actor Messages 列表中的任意位置右键，选择 Add Event。

   ![img](041-changingunitactor-addeventoption.jpg)

2. 选中刚创建的新动作后，就可以在 Actor Messages 窗口右侧看到它的事件选项。

3. 在 Msg Type 中，从列表里选择 Ability。

   1. 消息类型非常多，从单位创建、技能使用、单位死亡，到行为被添加或移除等等，应有尽有。
   2. 选择 Ability 后，我们就可以指定是哪一个技能会触发这条 Actor Message。

4. 在 Source Name 中，选择 Raynor Commando - Railgun Snipe。

   1. 因为我们把消息类型设为了 Ability，所以 Source Name 会列出游戏中的全部技能。

5. 在 Sub Name 中，选择 Source Cast Start。

   1. 因为消息类型是 Ability，所以 Sub Name 会列出技能的各个不同阶段。这样我们就能决定这条 Actor Message 要在技能执行过程中的哪个时刻触发。

   2. 技能阶段的例子包括：技能开始施放、施放完成、开始引导、停止引导、开始准备施放、停止准备施放等等。

   3. Source Cast Start 的意思是，当来源单位（也就是我们的单位）开始施放该技能时触发。所以当 The People's Hero 开始使用 Railgun Snipe 时，这条 Actor Message 就会被触发。

      ![img](042-changingunitactor-snipeevent.jpg)





### 创建 Term

对于这条 Actor Message，以及本教程中接下来要创建的其他消息，我们都不需要添加 Term。关于 Term 的创建方法，我们会在之后的教程里再讲。现在你只需要知道，它的创建方式和事件、消息的创建方式很相似即可。

### 创建消息

1. 在我们创建事件时，系统已经在它下面自动生成了一条默认消息。选中该消息后，就能在 Actor Messages 窗口右侧看到它的选项。

2. 保持 Target 字段为空。Target 指的是这条消息要发送给哪个 Actor。由于我们就是要把消息发给当前这个 Actor，因此无需指定 Target。

3. 将 Msg Type 改为 Animation Play。

   1. Actor 消息类型多得非常夸张。

   2. 我们可以通过它修改 Actor 的缩放、颜色/色调、不透明度，也可以改变它所使用的模型，甚至还能在 Actor Message 中创建其他 Actor。

   3. 当我们不再需要某个 Actor 时，也可以使用 Actor Message 销毁它。所以，如果事件是 “unit dies”，那么消息就可以是 “destroy actor”。

      ![img](043-changingunitactor-snipemessage1.jpg)

4. 在 Parameters 区域中，选中 Name 字段。在 Parameters 区域下方，你会看到一个 Name 下拉菜单，右侧还有一个 Customize 按钮。你可以把 Name 改成任意一个下拉列表中的可用选项，或者点击 Customize 自定义一个名称。

   1. 动画名称本身并不会影响动画内容；它只是方便我们在其他 Actor Message 中引用这段动画。
   2. 比如，我们可以在一条消息里说“开始播放名为 FunTimes 的动画”，然后在另一条消息里说“停止播放 FunTimes 动画”。

5. 仍然在 Parameters 区域中，选中 Animation Properties。随后在 Parameters 区域下方会出现一个 Animation Properties 下拉菜单。从中选择 Attack。

   1. 这里列出了游戏中所有可用的动画名称。但并不是每个模型都拥有所有动画。若要查看某个特定 Actor 可用的动画列表，可以在对象列表中右键该 Actor，并选择 预览 Actor。

      ![img](044-changingunitactor-previewactoroption.jpg)

      这会打开 预览er 窗口（我们会在以后的教程中更详细地介绍它），并显示该 Actor 的模型和相关信息。在预览窗口右侧中部有一个文件夹列表。展开 Animation Sequences 文件夹后，就能看到当前模型可用的动画。

      ![img](045-changingunitactor-previewer.jpg)

   2. 当你从下拉列表中选择了一个选项后，还会出现第二个下拉菜单，让你给动画添加更多修饰项。本例中我们不需要额外修饰。

6. 在 Parameters 区域中，把 Time Type 从 Automatic 改为 Duration，并把 Time Variant 从 -1 改为 2。这样动画会在 2 个游戏时间秒内播放完成。如果保持默认值，动画就会以默认速度播放并很快结束，而这会比技能实际施法时间更短。

7. Parameters 区域中的其他内容我们暂时保持不动。

这就完成了！我们已经为自定义英雄 The People's Hero 设置了新的生命值、护甲和能量数值，修改了武器，并加入了新的技能。通过这三部分教程，你已经初步接触了《星际争霸 II》编辑器。我们目前只是刚刚触及表面，但希望这套教程已经为你继续探索地形、触发器和数据系统，进而制作各类地图打下了扎实基础。未来的教程中，我们还会学习更多数据相关内容、更进阶的触发器概念等等。别忘了，游戏自带以及 Battle.net 上已有的大量 Mod 和地图中，也包含许多关于如何为自定义地图制作地形、触发器和数据的现成范例。下次见，祝你编辑愉快！
