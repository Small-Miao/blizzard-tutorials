# 地形模块 - 第 2 部分

## 放置一些 装饰物

该加一些场景装饰了！目前英雄们的军事基地还显得很空。我们会先通过添加机库、箱子和围栏来把这个地方搭建起来，还会在停机坪上加一些贴花，让它看起来更像真正的停机坪。

在《星际争霸 II》编辑器中，这类场景装饰物被称为 “装饰物”。到目前为止，我们一直在地形编辑器的地形图层中工作。若要放置 装饰物，则需要切换到 装饰物 图层。在顶部那排按钮中，找到那个看起来像一棵树的按钮，或者直接按 [D]。

![img](020-doodads-button.jpg)

## 装饰物 控制，以及筛选/搜索特定 装饰物

可用的 装饰物 有数百种，想找到需要的内容并不轻松。好在你可以设置筛选条件，也可以使用搜索框在需要时进行更精确的查找。

我们要给地图添加的第一个 装饰物 是 Garage。先用一些筛选条件来更容易地找到它。

找到 装饰物 筛选器。所有 装饰物 搜索筛选项都位于屏幕左侧，就在 装饰物 列表上方。

![img](041-doodads-filters.jpg)

在第一个下拉框中选择 Wasteland。

在最后一个下拉框中选择 Structures。

仅仅设置这两个筛选项，就能把原本几百项的列表缩减到大约 50 项。如果你还想查得更具体，可以在 Search 字段中输入想要使用的 装饰物 名称，或者其中一部分名称。

![img](042-doodads-search.jpg)

请注意，如果你设置了只查找某一类 装饰物 的筛选条件，可能就找不到自己要的 装饰物。例如，如果某个筛选条件限定为只显示 Environment 类 装饰物，那么 Garage 并不属于 Environment，因此它不会出现在列表中。

在 装饰物 列表中找到并选中 Garage 装饰物。

将这个车库放到地图上基地底部附近的位置。

![img](021-doodads-garage01.jpg)

这个车库当前朝南，这并不理想，因为它面向的是悬崖边缘，而不是基地中央。要旋转车库，按 [Space Bar] 或 [Escape] 进入选择模式，就像之前放置道路点时那样。然后选中我们刚刚放在地图上的车库。按住 [Control] 键，再在 装饰物 外部地面上按住鼠标左键拖动，直到车库朝北。

![img](022-doodads-garage02.jpg)

接下来，我们要在停机坪上放置一些 Decal 装饰物。

找到并选中 Decal 装饰物。

在车库附近的地图上放置几个 Decal 装饰物。

![img](023-doodads-decals01.jpg)

同一个 装饰物 可能有多个变体，这一点你在刚才放置的贴花上就能看到。如果你想在 装饰物 的不同变体之间切换，请进入选择模式并选中要修改的 装饰物，然后按 [<] 或 [>] 键循环切换变体。

![img](024-doodads-decals02.jpg)

继续放置 装饰物，直到停机坪装饰完成。

![img](025-doodads-decals03.jpg)

最后一个例子里，我们要在峡谷底部靠近水边的位置放置一些 Rock 装饰物。

找到并选中 Rock 装饰物。

尝试把这些岩石放在峡谷底部时，你会发现它们的放置预览是红色的，且无法放下。装饰物 和单位一样，也有某些放置限制。不能放在最低地形层级上就是其中之一。好在需要时，我们可以绕过这种限制。

![img](026-doodads-rocks01.jpg)

放置 装饰物 时按住 [Shift] 键，会让它们“忽略放置（ignore placement）”，这样无论是否有放置限制，都能摆放到任何位置。这样一来，你就可以把这些岩石放到峡谷底部。

![img](027-doodads-rocks02.jpg)

继续在基地周围和峡谷底部放置 装饰物，直到你对整体布局满意为止。下面是我们的结果：

## 装饰物 属性

地图上的 装饰物 有许多可调选项。双击一个已放置的 装饰物 会打开其 Object Properties 菜单，显示可用的各种设置，包括位置、高度、旋转和缩放。
