# 地形模块 - 第 3 部分

## 放置一些单位

现在基地已经初具规模，我们应该放上一些陆战队员来负责警戒，也让场景更有生气。

切换到单位图层来添加单位。单位图层按钮的图标是一只跳虫，位于工具栏上地形图层和 装饰物 图层按钮之间。你也可以按 [U] 直接切换。

## 单位类型、筛选/搜索

和 装饰物 一样，在查找要放置的单位时也有多种筛选选项和搜索功能。一般来说，放置单位的规则与放置 装饰物 相同。你可以放置、旋转、切换变体，以及忽略放置限制。

放置单位与放置 装饰物 的一个显著区别在于玩家编号。放置单位时，你必须选择这些单位归哪个玩家所有。你既可以通过键盘上的数字键切换玩家编号，也可以通过玩家筛选选项来修改。

如下图所示，我们为玩家 0 放置了一些面向公路、守卫路障的陆战队员，还放置了几座导弹塔、一座兵营和一个指挥生物穹顶。我们还为玩家 1 放下了几名陆战队员和一个 Jim Raynor (Commando) 单位。

## 单位属性

双击单位会像双击 装饰物 一样打开它的 Object Properties 窗口。虽然这里可用的选项不同，但思路是一样的。你可以在这个窗口中修改玩家编号、旋转、位置等。

其中有些选项稍微高级一些，稍后会在术语表文章或更进阶的单位教程中讲到。
