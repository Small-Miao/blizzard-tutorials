# 地形模块 - 第 1 部分

![img](000-terrainexample.jpg)

在这个共三部分的教程中，你将一边制作一张类似《自由之翼》战役第一关的小型冒险地图，一边熟悉《星际争霸 II》编辑器提供的诸多功能。

我们会先搭建一个任务起始区域，包含英雄单位、他们生活与工作的军事基地，以及周围的一些植被。

## 简介

默认情况下，启动编辑器后首先打开的就是地形编辑器。这是你创建环境布局与外观的地方，也是在游戏开始时放置装饰物、单位和建筑的位置。

用于修改地形和放置单位的控制项被划分在不同的“图层”中。比如地形图层用于调整地图布局和环境，单位图层用于放置单位，此外还有其他几个图层，本教程中大多数都会用到。

## 开始之前

在 Agria 地块集中新建一张地图（文件 > New...）。起始纹理选择 Agria Dirt。创建新地图时，你可以选择地图使用哪些“依赖项（依赖项）”。你可以把依赖项理解为一组单位、地块集和选项。《星际争霸 II》中提供了多种依赖项。Melee (Liberty) 依赖项包含标准多人和天梯对战中使用的全部单位与设置；Campaign (Liberty) 则包含战役中的全部内容，例如凯瑞甘、泽拉图和雷诺等单位。这里我们选择 Campaign (Liberty) 依赖项，这样就能使用战役中的全部单位与建筑，以及一些标准多人模式里没有的额外环境装饰物和 装饰物。最后，将地图的 Width 和 Height 设为 112 x 112。

![img](001-newdocumentdialog.jpg)

## 创建地形

我们首先要使用的是地形图层，在这里修改地图地表纹理和地貌。要切换到地形图层，按下 [T] 键，或者点击那个图标为青绿色双峰山的按钮：

![img](002-terrainlayer-button.jpg)

### 悬崖

英雄们工作的军事基地会建在一处大峡谷边缘，因此我们需要使用悬崖工具为峡谷创建一些悬崖：

在窗口左侧、小地图正下方，有一排与不同地形“画笔”对应的按钮。选择 “Cliff” 画笔按钮。它的图标是一段悬崖和一个绿色向上箭头。

这里的“画笔（brush）”是一个泛指。在编辑器里，任何你选择后可用于添加、修改或移除地形、纹理、单位等内容的工具，都被称为画笔。

接着，我们需要为悬崖画笔选择一个要执行的“操作（operation）”。选择 “Lower Cliff” 操作，通过向下压低地形来创建悬崖。“Lower Cliff” 的按钮图标是一段悬崖和一个红色向下箭头。之后你可以选择画笔的大小与形状，并决定要绘制哪种悬崖类型。这里我们暂时使用 Organic Cliff。

通过单击或按住鼠标左键来使用画笔；按住鼠标右键并拖动鼠标则可以移动地图视角。正如图中所示，我们把视角移动到了地图左下区域，并在地图左下侧挖出了一些悬崖。

![img](003-cliffs-canyon.jpg)

接下来，使用 Raise Cliff 操作创建一段向峡谷中伸出的人工高台悬崖。这里将作为停机坪。

![img](004-cliffs-manmade.jpg)

停机坪需要有坡道，否则就无法到达。选择 Add Ramp 画笔。坡道只能绘制在悬崖边缘，不能直接画在平地上。

![img](005-cliffs-ramp.jpg)

继续之前，先保存地图。如果编辑器因为自动更新重启电脑、停电，或者家里的宠物不小心拔掉电源而意外关闭，你的进度就可能丢失。与其在丢了 5 小时工作成果后去埋怨供电公司，不如养成经常保存的习惯。

### 纹理

现在我们已经做出了悬崖，可以开始考虑地图上要铺哪些纹理了。我们不想让整张地图都被泥土地面覆盖，所以还会铺上一些草地和混凝土地面。

选择纹理画笔，它是可用画笔那一排最左边的按钮。

这里有很多不同的操作，包括 Add Texture、Remove Texture、Blend、Smudge、Fill 等。大部分纹理绘制我们会使用 Add Texture，不过你也可以自由试试其他操作。纹理画笔还提供多种控制纹理绘制速度、形状、大小和风格的选项：

Increment - 这个选项控制你按住鼠标左键时纹理被涂上的速度。

Size - 增大这个选项的滑块可提升纹理画笔的半径。

Speed - 作用与 Increment 选项类似。

我们将选择 Concrete 纹理，把它涂在停机坪和停机坪坡道上。

![img](006-textures-concreteonhelipad.jpg)

继续在基地周围铺设纹理。现在，我们的英雄基地周边有了适合摆放建筑和机库的混凝土地面，也有了草地区域和泥土小路。

![img](007-textures-completedtextures.jpg)

### 高度

峡谷通常由水流侵蚀形成，所以我们打算在峡谷底部放置一条河流。在放水之前，先要压低一部分地形，挖出供水流经过的沟槽。我们可以使用 Height 画笔来抬高或降低地形，而不生成悬崖。借助这个画笔，我们可以制作山丘、山谷、陨坑，甚至土堆或落叶堆。

选择 Height 画笔按钮，它看起来像一座蓝色的小山，位于悬崖画笔左侧。

选择 Lower 操作。

使用该画笔在峡谷中挖出一条沟槽。

![img](008-height-jaggedditch.jpg)

有时使用高度画笔后，地形边缘会显得过于尖锐。我们可以使用 Smooth 操作来平滑地形高度，消除这些锯齿边缘。

![img](009-height-smoothditch.jpg)

### 水

现在可以让水流进这条沟槽了。

选择 Water 画笔按钮，它看起来像一大滴水。

水画笔只有两种操作：Add Water 和 Remove Water。选择 Add Water 操作（即使它已经高亮），以打开可放置的不同水体类型列表。

把一些水放到我们刚刚在峡谷中挖出的沟槽里。

![img](010-water-toohigh.jpg)

此时水面很可能悬浮在峡谷上方。要修正这一点，使用 Edit Water 按钮打开一个新的窗口，里面包含大量水体设置。当前我们需要关注的是 Height 设置。拖动滑块调整水面高度，直到它自然地落在沟槽中，而不是漂浮在上方。这里还有许多其他选项可以尝试。水看起来合适后，点击 Okay 关闭窗口。

![img](011-water-fitsinditch.jpg)

继续放置水体，直到整条沟槽都被水填满。

![img](012-water-finished.jpg)

### 道路贴片

我们的军事基地将通过一条四车道公路通行。要制作这条公路，我们将使用 Road 画笔。

选择 Road 画笔，它位于 Height 画笔按钮的左侧。

当前每个地块集只有一种 Operation 和一种 Type。

单击鼠标左键会放置一个道路点。道路点会自动与附近的其他道路点连接。若要放置一个不与附近道路点连接的道路点，请在放置时按住 [Control] 键。

![img](013-roads-twopoints.jpg)

我们已经放置了足够多的道路点，使公路能够沿着峡谷蜿蜒前进，并在到达军事基地后向左转，一直延伸到地图边缘。

![img](014-roads-placed.jpg)

如果你需要调整道路，可以进入“选择模式（selection mode）”来修改道路点。要进入选择模式，按下 [Space Bar] 或 [Escape]。这时你应该能看到道路点位置显示为绿色金字塔。要移动它们，单击并拖动即可；要旋转某个点，先选中它，然后按住 [Control] 和鼠标左键，再拖动鼠标。

![img](015-roads-selectionmode.jpg)

道路贴片不会显示在小地图上。为了让玩家知道道路位置，我们在道路下方涂上了 Concrete 纹理。

![img](016-roads-concreteforminimap.jpg)

### 植被

我们马上就可以开始在地图上放置装饰物和单位了，不过在此之前，先补上一些小型植被。在编辑器中，树木和灌木这类较大的植被通常由设计者手动、精确地放置；而草和花这类较小的植物则通常通过 Foliage 生成器生成。这样做的好处是不必手动摆放成千上万个草丛装饰物，另一个更重要的优势是，这种方式对游戏性能的压力更小，因此运行会更流畅。

在开始之前补充一点：在 Low 图形设置下，看不到植被。更具体地说，游戏中的 “Terrain Quality” 设置决定是否显示植被。

选择 Foliage 画笔，它的图标是一棵树，位于 Cliff 画笔右侧。

选择你希望的植被密度，然后点击 Generate Foliage 按钮。这里我们使用 0.50 的密度。

![img](017-foliage-onroad.jpg)

你可能会注意到，植被也被生成到了公路上。为了避免这种情况，我们需要使用 Disallow Foliage 操作，在不希望出现植被的区域进行绘制。

![img](018-foliage-disallow.jpg)

切回 Allow Foliage 操作，然后再次生成植被。现在，植被已经生成到整张地图上，但不会出现在我们不想要它出现的道路上。

![img](019-foliage-generated.jpg)
