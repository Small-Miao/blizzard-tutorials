# 地形模块 - 第 4 部分

## 玩家属性

我们可以在 玩家属性 窗口中修改每位玩家的颜色、贴花、种族等设置。这里我们要把玩家 1 的单位设为蓝色，并让玩家 1 固定为人类。

打开编辑器顶部的 “Map” 菜单，然后点击 “玩家属性...”，即可打开 玩家属性 窗口。

在左侧列表中选择 玩家 1，然后将 Color 选项从 (Any) 改为 Blue，再把 Race 改为 Terran。

![img](035-playerproperties.jpg)

这个窗口中还有其他一些可以设置的选项。这里我们只把玩家 1 的种族改成了 Terran，其余选项保持默认不变。
