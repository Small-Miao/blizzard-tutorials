# 触发模块 - 第 3 部分

## V. 使用点的触发器

点（Point）在触发器中有很多用途。它们可以作为在某个点生成单位的参照、命令单位移动到指定位置、在地图某个位置创建效果，等等。点在编辑器中可见，但游戏中不可见。

![img](039-placepoints-placed.jpg)

放置和修改点的方式，与放置和修改 装饰物、单位的方式相同。

### A. 放置点

首先，我们需要先放置一个点，之后才能在触发器中使用它。

1. 打开地形编辑器，按 [P] 选择点图层。

2. 在小地图正下方那排按钮中，选择看起来像大号向上箭头的 Normal Point 按钮。它是最左侧的按钮。

3. 将视角移动到农田区域，在农田中央单击鼠标左键放置一个点。

4. 如果你想修改点的名称，可以在左侧的点列表中选中它，然后按回车打开 Point Properties 窗口。

![img](040-placepoints-placedfarm.jpg)

### B. 为庄稼兴趣点添加 Ping

现在我们已经有了一个点，就可以在触发器中引用它了。

1. 切回触发模块，选中 Discover Objective 触发器。

2. 在该触发器末尾添加一个新的 “Create Ping Facing Angle” 动作。

3. 在 “Position” 值中，选择我们刚才在地形编辑器中创建的点。记得在弹出窗口中点击 “Value” 单选按钮，这样才能看到地图上已有点的列表。

4. 在 “Model” 值中，选择 “Ping Objective” 或 “Ping Boss”。

选择 Ping 模型时，你可以在搜索框里输入 “Ping”，以查看所有可用的 Ping 模型。

![img](041a-pingcrops-pingselection.jpg)

5. 将 “Color” 设为任意看起来合适的值。如果保留黑色，Ping 会被隐藏，因为它所使用的小地图未探索区域本来就是黑色的。这里我们把 Ping 颜色设为绿色。

6. “Duration” 可以自由设置。我们这里将持续时间设为 0，这样 Ping 会永久存在，直到通过触发器动作将其移除。

![img](041b-pingcrops-pingaction.jpg)

当目标创建出来时，这个 Ping 也会随之出现，提示玩家应该前往哪里。

### C. 起始位置与玩家属性

Start Locations 是近战地图中带有特殊属性的点。在近战地图里，玩家的主基地和农民会生成在 Start Location，游戏开始时玩家镜头也会以这里为中心。

我们会把一个 Start Location 放在玩家 1 的单位正上方。在下一节中，我们会在触发器里使用它，让地图开始时镜头居中到这个点。

也请为玩家 2、3、4 放置 Start Location 点：

![img](042-startlocations-placed.jpg)

接下来，我们要为我方单位和电脑单位设置一些玩家属性。我们可以在 玩家属性 窗口中修改每个玩家的颜色、贴花、种族和起始位置。

1. 通过编辑器顶部的 “Map” 菜单点击 “玩家属性...”，打开 玩家属性 窗口。

2. 对于这张地图，我们将设置下列属性：

![img](043-startlocations-playerproperties.jpg)

为 AI 玩家添加 Start Location 后，我们就可以为这些玩家启用 Campaign AI。启用后，地图上的那些潜地异虫单位会在我方单位靠近时自动出土。不过这个功能我们稍后再详细说明。给电脑玩家设置好 Start Location 之后，你会注意到地图上放置的 Start Location 点会变成对应玩家的颜色：

## VI. 地图初始化触发器

这一节里，我们会创建几个 “Map Initialization” 触发器。它们会在地图载入完成时执行，并在任务开始时设置多项游戏选项和初始状态。这些触发器会让玩家单位与殖民者以及军事前哨单位结盟，同时设置任务开始时的镜头位置，并启用我们的任务目标。

和前面一样，先创建一个文件夹来存放这一节要做的所有触发器。按 [Ctrl+G] 新建文件夹，并命名为 “Map Initialization”。

### A. 同盟关系

你在测试地图时可能已经注意到，由电脑玩家 2 和 3 控制的军事前哨单位和殖民者单位会在看到英雄单位时主动攻击。将玩家 1、2、3 设为盟友后，就不会再发生这种情况。

为此，我们需要在刚创建的 “Map Initialization” 文件夹中，新建一个名为 “Alliances” 的触发器。

#### 事件：

为这个触发器创建一个 “Map Initialization” 事件，让它在地图开始时运行。

#### 条件：

无

#### 动作：

1. 创建一个 “Set Alliance” 动作，并将 “Source” 设为 玩家 1，“Target” 设为 玩家 2。这里有多种 “Alliance Setting” 可选。我们使用 “Ally”，这样我们会与玩家 2 友好，但不会共享视野；只有我方单位会为地图开视野。

2. 再创建一个 “Set Alliance” 动作，将 “Target” 设为 玩家 3，并把 “Alliance Setting” 同样设为 Ally。

3. 考虑到军事单位与殖民者之间也可能发生互动，我们还把 玩家 2 和 玩家 3 也设成盟友。

![img](045-mapinit-alliances.jpg)

### B. 启用战役 AI，让异虫单位出土

除了坑道虫和雷兽之外，我们还在地图上放置了不少其他异虫单位，包括 Burrowed Zergling、Burrowed Roach 和 Burrowed Hydralisk。可如果现在就带着单位在地图上到处走，真正会主动现身与我们交战的，只有雷兽，因为只有它有专门的出土触发器。其他潜地单位仍会一直埋在地下。

我们当然可以给这些单位一个个写出土触发器，但如果改为启用战役 AI，那么所有这些埋地敌军都会在我方单位靠近时自动出土。

创建一个名为 “Start Campaign AI” 的新触发器。

#### 事件：

为这个触发器创建一个 “Map Initialization” 事件，让它在地图开始时运行。

#### 条件：

无

#### 动作：

创建一个 “Start Campaign AI For Player” 动作，并将 “Player” 设为 4。

地图开始时，我们还会把镜头移动到我方单位附近，并以黑屏淡入来营造一点戏剧效果。这个新触发器会命名为 “Camera”。

![img](046-mapinit-startcampaignai.jpg)

### C. 淡入地图并让镜头居中到英雄

#### 事件：

1. Map Initialization

#### 条件：

无

#### 动作：

1. 添加一个 “Pan Camera” 动作。将 “Point” 设为 Start Location 001（记住，你可以通过点击 “Value” 单选按钮，查看之前创建过的点列表），并把 Duration 设为 0.0。这样镜头会立刻切到我们的起始位置，而不是花一段时间慢慢平移过去。

2. 添加一个 “Fade In/Out” 动作。将 “Fade In” 设为 “Fade Out”，将 “Duration” 设为 0.0，“Color” 设为黑色（0%, 0%, 0%）。这样游戏开始时就会是黑屏状态，方便我们之后淡入。

3. 再添加一个 “Fade In/Out” 动作，让画面在 2 秒内淡入。

![img](047-mapinit-camera.jpg)

#### 保存并测试！

现在，地图初始化触发器都设置好了，再次进入游戏看看效果。

![img](048-mapinit-testingitout.jpg)

游戏开始时，我们应该已经与玩家 2 和 3 结盟，镜头也会对准英雄单位。当我们在地图上移动时，那些散布的异虫单位应当会出土并攻击我们。
